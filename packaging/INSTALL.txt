资料匣 · FolioChest 安装版（开发版本，尚未完成真机验收）

Windows
  x64 对应 amd64（Intel/AMD 64 位系统）；x86 对应 386（32 位）。
  双击 setup.exe，安装到当前用户的 LocalAppData/Programs/FolioChest。
  不要求管理员权限。开始菜单添加“资料匣”，桌面快捷方式可选。
  安装不自动启动程序，也不启用登录自启动。
  仅面向 Windows 10 或更新系统；x86 包为实验性构建。
  从系统“已安装的应用”卸载。升级/卸载前请在网页退出资料匣。
  x86 与 x64 不并排安装，切换架构请先卸载旧版。
  当前无代码签名，系统可能提示未知发布者，请核对来源和 SHA-256。

Linux
  Debian/Ubuntu：sudo apt install ./foliochest-版本-linux-amd64.deb
  Fedora：sudo dnf install ./foliochest-版本-linux-amd64.rpm
  ARM64 设备选择 arm64 文件。RPM 元信息中对应 aarch64，x64 对应 x86_64。
  安装后从应用菜单点击“资料匣”，自动打开默认浏览器。
  安装不启动服务，不创建 systemd 服务，不启用登录自启动。
  系统凭据解锁仍需要桌面的 Secret Service；无可用凭据库时不回退明文。
  升级/卸载前，请在每个使用者的网页中退出资料匣并关闭登录自启动。
  卸载：sudo apt remove foliochest 或 sudo dnf remove foliochest。
  从免安装版迁移时，先移除旧的用户级快捷方式，避免遮盖系统应用入口。

数据与设备设置
  安装包不携带、不自动创建、不搬动资料库；资料目录由用户选择。
  卸载只删除安装包拥有的程序文件和入口，不删除用户资料或本机设备配置。
  Windows 卸载清理指向本安装路径的资料匣自启动登记，不清理其他实例。
  Linux 包管理器不扫描或修改各用户的家目录，请事先自行关闭登录自启动。
  设备凭据仍会保留；若不再使用，请在卸载前于网页关闭设备授权。
  关闭浏览器不退出程序；退出请使用网页“退出资料匣”。

构建与限制
  Linux 安装包由 nFPM 生成；Windows 安装向导由 NSIS 生成。
  当前只做编译、安装包内容和元数据检查，不代表真机安装/升级/卸载验收。
  macOS、Windows ARM64、签名、自动更新暂未提供。
