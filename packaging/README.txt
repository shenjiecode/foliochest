资料匣 · FolioChest — 免安装开发版

Windows
  将压缩包完整解压到固定目录，双击 foliochest.exe。
  程序不显示控制台，启动后会打开默认浏览器。
  当前未做代码签名，系统可能提示未知发布者；请核对来源和校验和。

Linux
  将压缩包解压到固定目录，执行 ./foliochest。
  要从应用菜单点击启动，在解压目录执行：sh install-shortcut.sh
  此操作只添加当前用户的应用入口，不启用登录自启动。
  部分文件管理器也允许双击可执行文件，具体行为取决于桌面设置。
  需要默认浏览器与 xdg-open；文件夹选择需要 zenity 等辅助程序。
  移除应用入口：sh install-shortcut.sh --remove

使用
  默认界面地址：http://127.0.0.1:7463/
  首次在网页选择或创建资料库。用户不需要安装 Go 或 Node.js。
  重复点击会打开正在运行的同一本机配置实例，不重复启动服务。
  关闭网页不会停止后台；通过网页“退出资料匣”停止服务并锁定资料库。
  只启动后台、不弹浏览器：foliochest --background（Windows 为 foliochest.exe）。
  登录自启动、设备自动解锁、记住浏览器是分别选择的设置，默认关闭。

升级与数据
  先保存草稿并从网页退出旧程序，再替换程序文件；不要覆盖真实资料目录。
  旧版本没有启动锁时，不会复用旧进程，请先退出旧版本。
  本机配置默认仍位于系统配置目录的 keyfolio 子目录，不随解压目录移动。
  本包是免安装分发，并不表示资料和设备状态都写在程序旁边。
  资料库位置由用户选择。本机设备配置不要与资料库一起同步。
  从旧版升级后，请在设置里重新保存已启用的自启动项，使其使用 --background。

限制
  当前为实验性版本，建议只使用合成测试资料。
  交叉构建不是 Windows/Fedora 真机验收；macOS 暂不提供发行包。
  当前没有托盘、独立桌面窗口、自动更新或签名；不是正式安装包。
